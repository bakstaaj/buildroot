API Contract

CGI entrypoint: /cgi-bin/pluto-radio-api

Use the path query parameter for logical routes. POST requests use JSON bodies and all responses are JSON.

TX modes are tone, carrier, am, fm, and cw. AM/FM can use a built-in test tone or app-provided signed 16-bit mono PCM from a safe file/FIFO path.
